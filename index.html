如何共創？GitHub 開源社群共創完整指引指南

《CyberStriker》由全體玩家共同打造！無論您是資深工程師、動漫繪師，或單純熱愛格鬥遊戲，都能輕鬆參與

1. 你可以為遊戲共創什麼內容？

設計全新英雄外觀 (Skins)

為遊戲自訂原創科幻機甲、動漫熱門角色或荒野亂鬥英雄塗裝，配置專屬光軌與量子反應爐色彩。

擴充武器與招式庫 (Skills)

設計嶄新的 30 款武器攻擊方式（例如：追蹤浮游砲、裂地火浪、居合拔刀術等），定義公平傷害數值。

修復問題與流暢度優化 (Code)

改善手機觸控虛擬搖桿手感、優化 60 FPS 物理判定幀數、修復連段邊界判斷或瀏覽器相容性。

提議玩法與許願池 (Ideas)

不懂程式也能玩！到 GitHub Issues 提出您的遊戲創意、平衡性調整建議或平衡數據回饋。

2. 手把手共創實戰 4 步驟

第 1 步：Fork 專案倉庫（一鍵複製）
點擊官方 GitHub 倉庫右上角的 Fork 按鈕，將整份遊戲代碼複製一份到您的 GitHub 空間中。
第 2 步：修改對應代碼檔案（檔案架構一覽）
• 想新增造型外觀：打開 js/data/skins.js，複製現有範例並填寫您的角色名稱、十六進制主題色彩（themeColor）、光軌特效說明。
• 想新增武器招式：打開 js/data/skills.js，設定招式名稱、傷害（Damage）、冷卻時間（Cooldown）。
• 想微調骨骼部件：打開 js/engine/character_renderer.js 查看標準尺寸規格。
第 3 步：本機免環境即時測試（秒開即測）
本遊戲是純前端架構！電腦上直接雙擊打開 index.html，或在 VS Code 點擊 Live Server，就能在自己瀏覽器中立即試玩、測試自己新做的英雄外觀與招式！
第 4 步：提交 Pull Request (發起合併請求)
在您的 GitHub 頁面點擊 Contribute → Open Pull Request，寫下您的作品名稱與設計亮點。作者審核通過後，您的作品將正式上線給全世界所有玩家遊玩！

3. 官方審核三大黃金原則（維持 100% 公平對稱競技）

  • 判定盒對稱一致：所有外觀的受擊碰撞盒（Hitbox）與生命值完全相同，杜絕任何因模型過小或手長而產生的不公平優勢。
  • 零數值課金破壞：武器招式數值嚴格遵循傷害與冷卻平衡模型，純外觀換裝不得附帶任何攻擊力加成。
  • 代碼無毒透明：提交之代碼不得夾帶外部未知腳本，維護全球玩家遊戲環境純淨。
