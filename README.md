## 🌟 核心特色與系統架構

### 1. 🔐 雙軌 Google 登入認證與跨裝置雲端存檔 (The Authentication Gateway)
- **途徑一：手動輸入 Gmail 信箱**：信箱格式防呆校驗、自訂戰神暱稱（2~12 字元）。新玩家首次輸入贈送 1,200 能量幣與 3 套初始造型；老玩家自動還原所有進度與戰績。
- **途徑二：電腦現有 Google 帳號清單**（參考《條碼戰士》多帳號切換體驗）：自動偵測並展示已登記之 Google 帳號卡片，支援一鍵秒速切換。
- **備用途徑：訪客試玩體驗**：免帳號即時體驗全難度對戰 AI 與自由格鬥訓練營。

### 2. 💥 量子逆轉爆發機制 (Quantum Burst System)
- 每回合限用 1 次（或挨打累積 500 點能量槽）。
- 在受擊硬直 (Hit Stun) 中同時按下 **[J] + [K]** 或 **[B]**（或點擊觸控 **BURST** 鍵），啟動前 10 幀無敵，爆發直徑 300 像素金色力場，強推近身對手至 3 個身位外的中場安全距離，徹底化解新手被逼在版邊連續壓制打到死的挫折感！

### 3. 🥋 8 大肢體骨骼與 12 種武打姿態 (Articulated Skeletal Engine)
- 8 大骨骼部件：頭盔發光目鏡、胸甲量子反應爐、腰帶骨盆、左右上臂、左右前臂拳套、左右大腿、左右小腿戰靴。
- 12 種動作姿態：待機預備、向前邁步、後撤防守步（自動高防）、垂直起跳、跳躍攻擊、下蹲防守、高段格擋、下段格擋、刺拳直擊、重力猛踢、受擊硬直、倒地翻滾起身（享 15 幀無敵）。

### 4. ⚔️ 十大核心技能池與賽前 15 秒「10 選 3」配置
- **SK-01 能量脈衝彈**：直線高速飛行道具，逼跳牽制 (CD 3.0s / Dmg 120)
- **SK-02 升龍衝天擊**：前 4 幀全身無敵，斜上方昇龍打擊，極致防空 (CD 4.0s / Dmg 160)
- **SK-03 音速滑踢**：貼地下段突進，命中擊倒，站防無效必須蹲防 (CD 3.5s / Dmg 130)
- **SK-04 躍空震地砸**：空中翻騰下砸中段破防，蹲防無效必須站防 (CD 5.0s / Dmg 170)
- **SK-05 幻影反擊壁**：22 幀架招力場，受近戰肉搏時直接反制擊暈對手 (CD 6.0s / Dmg 190)
- **SK-06 虛空折躍斬**：穿透波導瞬移至對手正背後橫斬奇襲 (CD 7.0s / Dmg 150)
- **SK-07 百裂連擊衝**：前跨打出 5 連段密集體術，極高削防 (CD 4.5s / Dmg 180)
- **SK-08 磁暴重摔投**：前搖帶霸體，近身強抓貫入地面，完全無視防禦盾 (CD 6.0s / Dmg 210)
- **SK-09 奈米震波罩**：周身爆發環形脈衝，強行震退貼身敵人 (CD 8.0s / Dmg 100)
- **SK-10 超載終結砲**：反應爐超載聚能，貫穿全螢幕之離子巨砲 (CD 12.0s / Dmg 260)

## 🏗️ 系統技術與開源架構

1. **高效能 HTML5 Canvas 2D**：60 FPS 幀數鎖定，無任何外部胖引擎依賴，電腦手機秒開即玩。
2. **Web Audio API 程序化合成器**：純代碼震盪器生成打擊、格擋金屬回聲、離子雷射與賽博龐克合成背景旋律，零音訊資源 404 風險。
3. **無伺服器 WebRTC P2P (PeerJS)**：6 位數房間代碼直連配對，點對點同步輸入串流。
4. **小於 5KB 確定性戰鬥重播**：記錄種子與每幀位元遮罩輸入，一鍵生成 `CY-REP-XXXXXX` 短碼分享社群。
5. **Web Haptics API 觸覺震動**：刺拳輕震 15ms、重踢大招震動 50ms、大擊倒 80ms。
