## 🌟 最新核心特色與戰鬥系統改良

### 1. 🚫 全面刪除「下蹲」機制（統一站姿立回與主動量子防護罩）
- **玩家與 AI 皆不再具備下蹲姿態**：完全移除舊版下蹲判定，徹底消除下盤誤觸與龜蹲對峙。
- **純粹站姿立回與空中博弈**：所有地面防守統一透過專屬按鍵召喚【量子防護罩】，可正面抵銷一切常規打擊與遠程飛行道具（吸收 50% 傷害）；除指令摔技不可防禦外，站立防禦均能有效化解，戰鬥重心全面聚焦於走位、跳躍立回與神兵對轟！

### 2. 🥋 拳擊與踢腳改為「AI 專屬體術」
- **AI 專屬近身武藝**：刺拳直擊（Light Punch）與重力猛踢（Heavy Kick）改為 **AI 對手專屬體術**，AI 在貼身纏鬥或空中截擊時會運用靈活的拳腳體術壓制玩家。
- **玩家專屬神兵體系**：玩家不再使用基礎拳腳，而是將精力完全集中於自選裝備的 **5 大高科技神兵武裝**、主動防護罩、量子逆轉爆發與終極奧義！

### 3. 🎲 AI 武器機制：每局隨機抽取 3 把神兵
- 除了具備拳擊與猛踢體術之外，**AI 每次對戰開局皆會隨機抽取 3 把武器**。
- AI 的 3 把神兵並非隨意選取，而是**嚴格受當前挑戰難度約束**，只能從對應強度的專屬武器庫中抽取，確保不同難度下的對決風格鮮明且千變萬化！

## 🌐 多人連線對戰 (WebRTC P2P Direct Connect)

1. **6 位數專屬房間代碼**：點擊「建立房間」生成專屬 6 碼數字房號（如 `839201`）；好友輸入代碼即可一秒直連。
2. **賽前武器挑選與雙方準備機制**：
   - 房主與挑戰者在房間內可即時自選 5 項神兵武器出戰。
   - 雙方點選「準備完成」後，畫面觸發「3、2、1，開始！」倒數廣播，平穩過渡至擂台對決。
3. **高頻實時戰況同步**：
   - 房主 30Hz 權威廣播雙方血量、位置與能量槽。
   - 致命一擊即時廣播 `battle_ko`，雙方客戶端同幀觸發倒地、慢動作特寫與結算橫幅，絕無陣亡延遲！

## 🏗️ 系統架構與技術特點

- **純原生 HTML5 Canvas 2D + 60 FPS 確定性物理**：無重量級外部遊戲引擎負擔，秒開即玩。
- **Web Audio API 程序化合成器**：純代碼即時震盪合成打擊金屬音、離子光束、昇龍爆裂與賽博龐克合成波背景音樂。
- **PeerJS 無伺服器 P2P 通訊**：瀏覽器點對點直連傳輸，超低延遲對決。
- **量子反作弊守護 (Anti-Cheat Shadow Memory)**：記憶體影子混淆校驗，杜絕血量鎖定與瞬移竄改。
